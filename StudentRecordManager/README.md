
## Description

Student Record Manager is a console-based Java application designed to manage student information efficiently. The application allows users to store, view, search, and manage student records through a simple menu-driven interface.

This project was developed to strengthen core Java programming concepts, including object-oriented programming, user input handling, and data management.

## Features

* Add new student records
* View all student records
* Search for a student
* Update student information
* Delete student records
* Menu-driven console interface

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* Scanner Class for User Input
* Arrays / ArrayLists (depending on implementation)

## Learning Outcomes

Through this project, I practiced:

* Class and Object creation
* Encapsulation
* Data storage and management
* Conditional statements
* Loops
* User interaction through the console
* Problem-solving using Java

## How to Run

### Compile

```bash
javac StudentRecordManager.java
```

### Execute

```bash
java StudentRecordManager
```
