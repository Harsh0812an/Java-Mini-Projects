# Java Mini Projects

A collection of Java mini projects developed while learning Core Java, Object-Oriented Programming (OOP), File Handling, and application development.

This repository contains hands-on projects built to strengthen programming fundamentals and problem-solving skills through practical implementation.

## Projects

### Contact Manager

A console-based application for storing, managing, and viewing contact information.

### Music Player

A Java-based music player capable of playing supported audio formats using Java's built-in audio libraries.

### Shopping Cart

A console-based shopping cart system that allows users to add products, manage items, and calculate totals.

### Student Record Manager

A Java application for maintaining and managing student records through a menu-driven interface.

## Concepts Practiced

* Core Java
* Object-Oriented Programming (OOP)
* File Handling
* Exception Handling
* User Input Handling
* Menu-Driven Applications
* Java Collections
* Java Sound API
* Problem Solving
