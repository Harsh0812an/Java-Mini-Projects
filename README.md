# Java Mini Projects

A collection of Java mini projects developed while learning Core Java, Object-Oriented Programming (OOP), File Handling, and application development.

This repository showcases practical Java projects built to strengthen programming fundamentals, problem-solving skills, and software development practices.

## Projects

### Contact Manager

A console-based application for storing, managing, and viewing contact information.

### Student Record Manager

A Java application for maintaining and managing student records through a menu-driven interface.

### Shopping Cart

A console-based shopping cart system that allows users to manage products and calculate purchase totals.

### Music Player

A Java-based music player capable of playing supported audio formats using Java's built-in audio libraries.

### Password Strength Checker

A utility that evaluates password strength based on factors such as length, character variety, and complexity.

## Concepts Practiced

* Core Java
* Object-Oriented Programming (OOP)
* File Handling
* Exception Handling
* User Input Handling
* String Manipulation
* Menu-Driven Applications
* Java Collections
* Java Sound API
* Problem Solving
