# Music Player

## Description

Music Player is a console-based Java application that allows users to play audio files stored on their system. The project uses Java's built-in audio libraries to load and play supported audio formats through a simple menu-driven interface.

This project was developed to practice file handling, user interaction, and working with Java audio APIs.

## Features

* Play audio files
* Load music from the local system
* Simple console-based controls
* Supports common Java audio formats such as:

  * `.wav`
  * `.au`
  * `.aiff`

## Technologies Used

* Java
* Java Sound API (`javax.sound.sampled`)
* File Handling
* Exception Handling
* Scanner Class

## Learning Outcomes

Through this project, I practiced:

* Working with Java audio libraries
* Reading files from the local system
* Exception handling
* User input processing
* Building menu-driven applications
* Managing external resources

## How to Run

### Compile

```bash
javac MusicPlayer.java
```

### Execute

```bash
java MusicPlayer
```

## Supported Formats

* WAV (`.wav`)
