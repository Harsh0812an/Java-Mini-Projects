# Password Strength Checker

## Description

Password Strength Checker is a Java-based application that evaluates the strength of a password based on predefined security criteria. The program helps users create stronger passwords by identifying weaknesses and providing feedback.

This project was developed to practice string manipulation, conditional logic, and user input handling in Java.

## Features

* Password strength evaluation
* Checks password length
* Detects uppercase and lowercase characters
* Detects numeric digits
* Detects special characters
* Provides strength feedback to users

## Technologies Used

* Java
* String Manipulation
* Conditional Statements
* User Input Handling

## Learning Outcomes

* Working with strings in Java
* Input validation
* Conditional logic implementation
* Security-focused programming concepts
* Problem-solving and algorithm design

## How to Run

### Compile

javac PasswordStrengthChecker.java

### Execute

java PasswordStrengthChecker
