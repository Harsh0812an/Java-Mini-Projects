# Shopping Cart

## Description

Shopping Cart is a console-based Java application that simulates a basic shopping cart system. Users can add items, view their cart, calculate the total cost, and manage purchased products through a simple menu-driven interface.

This project was developed to practice Java programming fundamentals, object-oriented programming concepts, and data management techniques.

## Features

* Add products to the cart
* View cart contents
* Calculate total bill
* Manage multiple items
* Menu-driven console interface

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* Collections / Arrays
* User Input Handling

## Learning Outcomes

* Working with objects and classes
* Managing collections of data
* Implementing business logic
* Building menu-driven applications
* Problem-solving using Java

## How to Run

### Compile

javac ShoppingCart.java

### Execute

java ShoppingCart
